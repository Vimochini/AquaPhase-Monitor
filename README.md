# AquaPhase Monitor — Clausius–Clapeyron Verification

Open `index.html` in a browser to view the project page.

## Layout

- `index.html` — main web page (formerly `new.html`)
- `assets/images/` — figures used on the page
- `assets/video/` — demo clip
- `data/` — BMP280 sensor log (`Timestamp, Temperature_C, Pressure_hPa`)
- `docs/` — written report (`report.docx`)
- `archive/` — earlier version of the page (`earlier-version.html`, formerly `aq.html`)
